# Ilustraciones del configurador

Recursos incluidos en la aplicación; no requieren conexión durante su uso.

- `jardin.png`, `bosque.png`, `castillo.png`: ilustraciones de la referencia de Stitch proporcionada para el proyecto, extraídas de los enlaces de `crear_cuento_tema_neutro_salvia_pergamino/code.html` y normalizadas a PNG para el empaquetado Android.
- `isla.png`, `atico.png`, `caverna.png`: generadas para esta pantalla con la herramienta de imágenes de Codex, con dirección de acuarela de cuento infantil, sin texto.

La correspondencia con el catálogo se mantiene en `src/features/configurator/environmentArtwork.ts`.
